## Описание
Реализация алгоритма шифрования и дешифрования с использованием решетки Кардано размером 8x8. Проект включает в себя генерацию случайной корректной решетки и программы для работы с шифротекстом.

## Функционал
1. **Генерация решетки (`generate_grille.py`)**: Создает случайную решетку 8x8, удовлетворяющую условиям поворота на 90 градусов без наложения отверстий. Сохраняет ключ в файл `grille_key.txt`.
2. **Шифрование и дешифрование (`cardano_cipher.py`)**:
   - Шифрует текстовый файл, записывая символы в открытые ячейки решетки при последовательном повороте на 0°, 90°, 180° и 270°.
   - Дешифрует текст, извлекая символы из тех же позиций в том же порядке.

- Стандартные библиотеки: `random`, `sys`, `math`
